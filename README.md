# Manual Inventory Templates

The Inventory Templates app lets you maintain item planning parameters for many Business Central locations at once by setting them up in templates and synchronizing those templates to stockkeeping units (SKUs).

In Business Central, maintaining item planning parameters for multiple warehouses can be a hassle, because you must set up a stockkeeping unit (SKU) manually for each item, variant, and location combination. The Inventory Templates app is especially useful if you have multiple locations with the same item planning settings, for example, in service organizations whose vans are set up as Business Central locations.

This manual describes how to set up and use the Inventory Templates app.
